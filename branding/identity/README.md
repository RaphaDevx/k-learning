# Identity Assets

Logo-Dateien und App-Icons gehören in diesen Ordner.
Erstellt via K-Creative Designer (`/k-creative-designer` Skill in K-Creative-Cloud).

## Benötigte Dateien

### Logo
- `klearning-logo-primary.svg`   — K-Violet auf transparentem Hintergrund
- `klearning-logo-white.svg`     — Weiss auf transparentem Hintergrund
- `klearning-logo-black.svg`     — Schwarz (für helle Hintergründe)

### App Icons (PNG, kein transparenter BG — App Stores)
- `klearning-icon-1024.png`  ← App Store / Play Store Master
- `klearning-icon-512.png`
- `klearning-icon-192.png`   ← Android
- `klearning-icon-180.png`   ← iOS @3x
- `klearning-icon-120.png`   ← iOS @2x

### Favicon
- `favicon.ico`              ← 16+32+48px kombiniert
- `favicon-32.png`
- `favicon-180.png`          ← Apple Touch Icon

## Erstellen

```bash
cd ~/K-Creative-Cloud
claude   # MCP-Server laden
# Dann: /k-creative-designer aufrufen
```

Inkscape (via MCP) erstellt SVG → exportiert alle PNG-Grössen automatisch.
